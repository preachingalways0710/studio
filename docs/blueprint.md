# **App Name**: KidPoint Tracker

## Core Features:

- Student Profile: Create and manage student profiles including name, photo, birthday (for age), and initial point balance from CSV upload.
- Attendance Logging: Mark students as present for the month, awarding 10 points.
- Referral Points: Record the number of friends a student invited (and who attended) to award 30 points per friend.
- Point Deduction: Log point deductions for purchases made in the store.
- Real-time Point Tally: Display a continuously updated point total for each student.
- Student Search: Quickly find students by name via a search bar.
- Monthly Attendance Overview: Use a tool that analyzes attendance data for each month of the year and summarizes in an overview for all kids.

## Style Guidelines:

- Primary color: Cheerful blue (#64B5F6) to create a friendly and inviting atmosphere for kids.
- Background color: Light blue (#E3F2FD), subtly desaturated to provide a calm backdrop that's easy on the eyes.
- Accent color: Soft green (#A5D6A7), offering a contrasting element to draw attention to key interactive elements without being overwhelming.
- Font: 'PT Sans', a friendly, readable sans-serif, used for both headings and body text.
- Use clear and playful icons to represent actions and data, such as adding attendance, awarding points, and managing student profiles. Use icons consistently throughout the application to aid user comprehension and navigation.
- Design the dashboard with a focus on easy navigation. Student profiles with photos will allow for quick identification. Employ a clear, tabular format for attendance and points data, ensuring staff can efficiently update and view records. Keep the dashboard uncluttered by grouping related functions and using white space to separate elements.
- Incorporate subtle, cheerful animations when updating point totals or marking attendance. For example, a small celebratory animation could play when a student is marked as present or receives points for referrals. These animations should be brief and add to the positive user experience without distracting from the task at hand.
